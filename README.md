# Орбита-84

Веб-версия карманной LCD-аркады на React и TypeScript. Дальний спутник потерял связь с Землёй: задача пилота — перемещать приёмник по четырём секторам, собирать сигналы и сердца связи, не сталкиваясь с ракетами.

## Играть онлайн

Игра доступна по адресу: [bigpanda-it.github.io/orbita-84](https://bigpanda-it.github.io/orbita-84/).

## Запуск

```bash
npm ci
npm run dev
```

Приложение откроется по адресу `http://localhost:8080`.

## Управление

- `A` / `←` — влево;
- `D` / `→` — вправо;
- `P` / `Пробел` — пауза;
- `Enter` — старт или новая игра;
- экранные кнопки работают мышью и касанием.

## Игровые правила

- сигнал: +10 очков;
- каждый пятый сигнал увеличивает множитель (до ×4);
- сердце связи: +25 очков и восстановление одной жизни;
- ракета: потеря жизни и сброс серии;
- каждые 60 очков увеличивают базовую сложность и частоту появления объектов;
- каждые 30 секунд активной игры скорость дополнительно увеличивается на 5%.

Лучший результат сохраняется в `localStorage`. Звуки синтезируются через Web Audio API и не требуют внешних файлов.

## Проверка

```bash
npm test
npm run lint
npm run format:check
npm run build
```

Баланс и управление находятся в `src/game/config.ts`, чистая игровая логика — в `src/game/gameLogic.ts`, а юнит-тесты — в `src/game/gameLogic.test.ts`.
